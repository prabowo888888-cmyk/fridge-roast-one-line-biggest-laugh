# Fridge Roast: One Line, Biggest Laugh

One line roasting a smart fridge, written for the make.fun bounty of the same name.

## The entry

> My smart fridge has a screen bigger than my TV just to show me ads for milk I already own.

## Why this line

A smart fridge's biggest, most expensive feature is a giant touchscreen on its door, and the joke measures that screen against the one piece of furniture a screen is supposed to impress: the TV. The fridge wins the size contest and loses the point of it entirely, because the only thing it does with all that glass is advertise milk that is already sitting inside it. The turn lands in the last six words — the screen is not showing something useful, it is selling you a thing you have already bought, from a machine that knows you bought it.

The angle stays on the fridge itself: its screen, its ads, its milk. It steers clear of the two cracks everyone reaches for first, the fridge ordering groceries and the fridge spying on its owner. Every word is doing work — the TV comparison sets the scale, "just to" sets up the letdown, and "already own" is the punchline, with nothing left over to explain it.

## Run

```sh
python3 main.py
```

By default this writes the entry to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write somewhere else:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/fridge-out python3 main.py
```

The program checks the file it wrote: the bytes must match the entry exactly, the text must be 1–200 characters, a single line, with no trailing newline, and valid UTF-8.
